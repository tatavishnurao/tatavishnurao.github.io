projects

Selected systems and research prototypes. Each description is intentionally bounded to what is documented in the repository.

LatentPagedAttention-rs

github · architecture · technical report

A correctness-first Rust, Python, and cuTile experiment measuring the memory-compute trade-off of paged latent-cache decode attention on an RTX 4060. It asks whether a paged latent cache can be mutated and consumed directly on GPU without storing persistent full K/V tensors.

signalflow-rs

github · docs

A real-time-capable Rust DSP/log-Mel frontend for audio feature extraction. The current pipeline includes preprocessing to 16 kHz mono, framing, Hann windowing, FFT power spectrum, Mel filtering, log compression, streaming buffers, drop metrics, and Criterion benchmarks.

DubPatch

github · docs

An evidence-first review system for Sarvam-dubbed automotive Shorts. It produces preserved, review_required, or unable_to_verify states; it does not emit a universal accuracy score or autonomous certification.

GlyphPortrait

github · algorithm · limitations

A semantic digital micrography engine for portrait reconstruction. It takes a person image and a user-provided word prompt, extracts/vectorizes visual regions, generates coherent text streamlines, and renders the person using readable text.

SochDB / LoCoMo retrieval benchmarks

github

A reproducible benchmark lane for vector search and agent-memory retrieval. The useful distinction is separating retrieval quality, system overhead, workloads, raw outputs, and reports instead of collapsing the system into one headline score.

RealKV-Serve

github · reproducibility

A milestone-one compatibility and observability experiment for observing the paged KV-cache lifecycle of one deterministic Qwen3-1.7B request through the TensorRT-LLM PyTorch backend on an RTX 4060 Laptop GPU.
